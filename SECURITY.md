# Security Policy

## Reporting a vulnerability

Found something? Don't open a public issue for it — email the maintainer
directly so there's time to fix it before it becomes everyone's problem.

- Email: burrejak22 (via GitHub profile)
- Please include: what you found, where, and how to reproduce it.

Expect a response within a few days. If it's a real issue, it'll get fixed
and credited in the release notes (unless you'd rather stay anonymous).
